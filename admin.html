Configuration des paiements

🅿️ PayPal

Connecter votre compte PayPal

Entrez votre Client ID PayPal pour activer les paiements en ligne réels. Vos clients pourront payer directement via PayPal.

Non configuré
Comment obtenir votre Client ID PayPal :
1. Allez sur developer.paypal.com
2. Connectez-vous avec votre compte PayPal
3. Cliquez sur My Apps & Credentials
4. Créez une app ou sélectionnez une existante
5. Copiez le Client ID (mode Sandbox pour tester, Production pour les vrais paiements)

🏦 Virement bancaire

Ces informations seront affichées au client qui choisit le virement bancaire.

💳 Carte bancaire

✅ Le paiement par carte est toujours disponible. Il est simulé (aucune intégration bancaire réelle). Pour les vrais paiements carte, utilisez Stripe ou PayPal.
Pour intégrer Stripe (paiements carte réels), contactez un développeur avec votre clé publique Stripe. PayPal ci-dessus gère aussi les cartes via PayPal Checkout.
